# Portofolio Mesra Togatorop

Website portofolio statis menggunakan HTML, CSS, dan JavaScript. Tidak memerlukan instalasi Node.js.

## Menjalankan di laptop
1. Ekstrak folder ZIP.
2. Buka folder `portofolio-mesra` menggunakan VS Code.
3. Buka `index.html` di browser. Jika sudah memasang ekstensi Live Server, klik kanan `index.html` lalu pilih **Open with Live Server**.

## Ganti foto profil
- Siapkan foto profesional.
- Simpan di folder `assets` dengan nama `foto-profil.jpg`.
- Jika format foto berbeda, ubah nama file atau perbarui alamat gambar pada `index.html`.

## Tambahkan CV
- Simpan CV PDF di folder `assets` dengan nama `cv-mesra.pdf`.
- Tombol Unduh CV sudah diarahkan ke `assets/cv-mesra.pdf`.

## Ganti email
Di `index.html`, cari `emailkamu@example.com` lalu ganti dengan email aktif.

## Perbarui pengalaman
Lengkapi periode dan tugas Marketing Digital serta Account Executive hanya dengan informasi yang benar-benar sesuai pengalaman.

## Publikasikan dengan GitHub dan Vercel
1. Buat repository baru di GitHub, misalnya `portofolio-mesra`.
2. Upload seluruh isi folder ini ke repository (pastikan `index.html` berada di root repository).
3. Masuk ke https://vercel.com/new dan impor repository GitHub tersebut.
4. Untuk website HTML statis, biasanya tidak perlu Build Command. Jika diminta, pilih konfigurasi yang sesuai untuk static files dan pastikan Output Directory adalah root (`.`) atau kosong jika opsi tersebut diterima.
5. Klik Deploy dan buka URL yang diberikan Vercel.

## Sebelum dibagikan
- Pastikan foto, CV, email, dan semua informasi sudah benar.
- Lengkapi detail pengalaman yang masih berupa placeholder.
- Hapus atau ganti contoh proyek dengan hasil kerja asli yang boleh dipublikasikan.
